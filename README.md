# NetworkApps
Сетевые приложения 
Лабораторная №1 (Laba1) - Выдача ответа по протоколу http (Называется Laba_1), dns, file
Лабораторная №2 (Laba2) - Выдача на сервере текстовой строки из клиента
Лабораторная №3 (Laba3) - Сканер открытых портов локального IP-адреса
Лабораторная №4 (Laba4) - Сканер локальной сети на предмет имеющихся IP-адресов и открытых портов
Лабораторная №5 (Laba5) - Сниффер пакетов (с заголовками)
Лабораторная №6 (Laba6(2)) - Чат на TCP сокетах с возможностью создать группы для общения и передавать файлы любого формата (.png, .gif, .pdf, .docx и т.д.)
